# Apresentação profissional — Kathleen Dias

Site estático com apresentação de projetos, aula demonstrativa de Hardware e Software e quiz interativo.

## Estrutura

- `index.html`: conteúdo da página, formatado e identado.
- `style.css`: identidade visual e responsividade.
- `script.js`: navegação entre etapas e quiz.
- `assets/`: quatro imagens fornecidas para a aula (arquivos locais).

## Como abrir

Extraia o ZIP inteiro. Abra `index.html` no navegador. Para editar, abra a pasta inteira no VS Code. Não mova o `index.html` para fora da pasta, pois ele depende dos outros arquivos.

## Como publicar no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie todos os arquivos e a pasta `assets/` para a raiz do repositório.
3. Em Settings > Pages, escolha Deploy from a branch, branch `main`, pasta `/(root)`.
4. Aguarde a publicação e abra o endereço informado pelo GitHub.

As imagens estão no projeto e não dependem de sites externos. Os links para portfólio e curso abrem páginas externas e precisam de internet.

## Observações

As imagens foram fornecidas pela autora da apresentação. Confira as permissões de uso antes de disponibilizar publicamente, especialmente logotipos e ilustrações de terceiros.
